# Contributing

Switchyard is a solo project run with team-grade process so its history can be audited. The full rules are in [docs/engineering/conventions.md](docs/engineering/conventions.md).

Short version:
1. Every change starts from an issue.
2. Decisions go in `docs/adr/`.
3. Branch naming, Conventional Commits, one issue per PR, green CI before merge.
4. Squash-merge to `main`. `main` is always deployable.
