## Scope
RFC 8785 canonicalization plus SHA-256 for the evidence manifest, the plan manifest and the config fingerprint (secret-free). ADR-0012.

## Acceptance criteria
- [ ] Key-order and whitespace changes do not change the hash; any semantic change does
- [ ] Config fingerprint excludes secret values (tested with an allowlist)
- [ ] Golden-file tests
