## Why
ADR-0011. Crash-safe, auditable external mutations.

## Scope
`withIntent(logicalKey, expected, desired, execute, reconcile)` activity helper. Ambiguous outcome → intent `ambiguous` → the workflow pauses and reconciles.

## Acceptance criteria
- [ ] Test: worker killed after a create call → restart → no duplicate resource (F3)
- [ ] Test: create times out → paused_ambiguous → resolved by reconciliation (F4)
- [ ] Every intent writes an audit event
