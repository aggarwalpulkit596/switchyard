## Scope
Probe suite against a rehearsal instance: create order → read back → list by segment → invalid input rejected. Results are `pass|fail|inconclusive|error` with durations and redacted artifacts. A health check alone never yields a functional pass.

## Acceptance criteria
- [ ] Check identity and version recorded per result
- [ ] The runner uses least-privilege credentials only
