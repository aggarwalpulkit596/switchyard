# Documentation index

| Area | Location | Changes when |
|---|---|---|
| Product | `product/` | Scope or target user changes |
| Design | `design/` | Behavior, data or protocols change |
| Decisions | `adr/` | A constraining decision is made (append-only) |
| Spikes | `spikes/` | An assumption needs verification before building |
| Plan | `plan/` | Milestones or priorities change |
| Engineering | `engineering/` | Process or conventions change |
| Updates | `updates/` | Weekly (async status) |
| Learning | `learning/` | Every issue: study notes (read, understand, decide, execute) and glossary |
